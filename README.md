# Maths Primaire (PWA)

Projet indépendant du [compendium collège](https://github.com/Narkotine/compendium-maths).  
Site : https://narkotine.github.io/compendium-primaire/

- Base Vite : `/compendium-primaire/`
- Stockage : `compendium-primaire.*` · caches SW : `compendium-primaire-*` (ne touche pas collège / jeux)
- `npm run build` · `npm run preview` (port 4174) · `npm test` · `npm run test:e2e`
- Publication GitHub Pages : `npm run publish:gh` (branche `gh-pages`, sans Actions)
